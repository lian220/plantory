# Plantory — 식집사 사업기획

**우리집에 맞는 식물을 고르고, 원하는 모습으로 오래 가꾸는 서비스.**

현재 단계는 사업 아이템 분석·기획이다. 이 저장소에는 모바일 시각 기획서와 탐색용 서비스 시안이 들어 있다. 실제 식물 인식·상담 매칭·거래·관리 서버는 구현하지 않았다.

## 모바일 시각 기획서 열기

별도 설치 없이 `index.html`을 브라우저에서 열 수 있다. 로컬 서버를 사용하려면:

```sh
python3 -m http.server 8874 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8874 를 연다. PC에서도 모바일 폭으로 보인다. 네트워크 연결 없이 기획 문서와 시안을 탐색할 수 있으며, 외부 근거 링크를 열 때만 네트워크가 필요하다.

## 합의한 방향

- **모바일 전용.** PC 제품은 기획하지 않는다.
- 개인 식물 관리가 기본 경험이며 수형·성장, 공간·화분, 테라리움 제작으로 연결한다.
- 초기에는 방법·상품·전문가를 매칭하고 이후 직접 상담·키트·클래스를 검토한다.
- 제품 기능 목록과 돈을 낼 고객의 문제를 구분해 분석한다.
- 구현과 배포보다 사업 가설 비교·현장 인터뷰·수동 매칭 검증을 먼저 한다.
- 세부 가격·제휴 수수료·상담 운영 방식·지원사업 신청 자격은 아직 확정하지 않았다.

## 구성

HTML/CSS/JavaScript로 작성한 독립 문서다. 빌드·서비스 계정·API 키가 필요하지 않다. 기획 내용과 시안은 샘플이며 사용자 입력은 현재 화면에서만 사용한다. 외부에 요청을 보내거나 개인 정보를 저장하지 않는다.

## 서비스 시안 수정

`assets/concept.fragment.html`을 수정한 뒤 `python3 scripts/export-concept.py`로 `concept.html`에 반영한다. 기존 내장 아이콘과 단독 실행 형태를 유지하며, 다시 열어 동작을 확인한다.
