# Plantory — 식집사 사업기획

**우리집에 맞는 식물을 고르고, 원하는 모습으로 오래 가꾸는 서비스.**

현재 단계는 사업 아이템 분석·기획과 모바일 시안 검토다. 이 저장소에는 시각 기획서, 서비스 안내서, 탐색용 시안이 들어 있다. 실제 참가자 테스트·수요 검증은 아직 진행하지 않았으며 식물 인식·상담 매칭·거래·관리 서버는 구현하지 않았다.

## 내부 기획 문서 열기

별도 설치 없이 `index.html`을 브라우저에서 열 수 있다. 로컬 서버를 사용하려면:

```sh
python3 -m http.server 8874 --bind 127.0.0.1
```

브라우저에서 [로컬 기획서](http://127.0.0.1:8874)를 연다. 사업기획서·서비스 안내서·사용성 보고서는 PC에서 읽기 편한 내부 문서다. `concept.html`의 실제 서비스 시안만 모바일 폭을 유지한다. 네트워크 연결 없이 문서와 시안을 탐색할 수 있으며, 외부 근거 링크를 열 때만 네트워크가 필요하다.

## 합의한 방향

- **내부 문서는 PC 열람 기준.** 사업기획서·안내서·보고서는 넓은 화면에서 비교하고 읽기 쉽게 구성한다.
- **실제 서비스와 서비스 시안은 모바일 전용.** PC용 서비스 제품은 기획하지 않는다.
- 개인 식물 관리가 기본 경험이며 수형·성장, 공간·화분, 테라리움 제작으로 연결한다.
- 식물·원예 자재의 신품·중고 구매비용 비교를 공통 서비스로 기획한다. 시안에서는 가상 매물로 조건·총액 비교와 준비물 예산을 체험한다. 실제 가격·재고·판매처 데이터는 연동하지 않는다.
- 새 식물 입양 체크, 상담·분갈이 후 경과 관리, 비슷한 환경의 사례, 판매·분양 정보 카드와 소량 자재 구매·나눔을 포함한다. 상태를 공개하는 식물 아웃렛도 전체 설계에 포함하며 시안과 실제 운영 조건을 구분한다.
- 초기에는 방법·상품·전문가를 매칭하고 이후 직접 상담·키트·클래스를 검토한다.
- 제품 기능 목록과 돈을 낼 고객의 문제를 구분해 분석한다.
- 먼저 지인 중 식물 초보자가 모바일 시안을 사용해 본다. 첫 과업은 이름 미상 등록·모름 관찰 안내·첫 기록·기록 확인이며 모집 비용은 0원이다.
- 이후 사업 가설 비교와 온라인 수동 매칭을 검증한다. 창업자는 기획·운영, 전문 안내는 전문가 협업으로 준비하며 현재 확보된 파트너는 없다.
- 초기 운영 범위는 전국 온라인이고 투입 가능 시간은 주당 16시간 이상이다. 초보 지인 2~3명을 후보로 혼자 체험한 뒤 메신저 질문 5개에 답변받을 계획이다. 공유 자료가 준비되면 이번 주(2026-09-30 대화 기준)에 부탁할 계획이며, 실제 참여 수락·날짜·상담 제공 조건은 아직 정하지 않았다.
- 세부 가격·제휴 수수료·상담 운영 방식·지원사업 신청 자격은 아직 확정하지 않았다.

## 구성

HTML/CSS/JavaScript로 작성한 독립 문서다. 빌드·서비스 계정·API 키가 필요하지 않다. 기획 내용과 시안은 예시이며 입력과 기록은 현재 열린 페이지의 메모리에서만 사용한다. 새로고침하거나 창을 닫으면 초기화되고 외부 요청·사진 전송·영구 저장은 수행하지 않는다. 최신 확인 범위는 [확인 기록](docs/verification.md)을 따른다.

## 서비스 시안 수정

`assets/concept.fragment.html`은 등록·관찰과 화면 연결을, `assets/prototype-commerce.fragment.html`은 구매·예산을, `assets/prototype-care.fragment.html`은 입양·경과·사례·분양과 나눔 카드를 담당한다. 구매 금액 계산은 `assets/prototype-commerce-model.js`에 둔다.

수정 후 `python3 scripts/export-concept.py`를 실행하면 모든 모듈과 기존 아이콘을 `concept.html` 하나에 넣는다. 단독 HTML을 다시 열어 동작을 확인한다.

계산·내보내기 검증:

```sh
node --test scripts/test-commerce.cjs
python3 -m unittest discover -s scripts -p test_export.py
```

화면 흐름은 Codex 인앱 브라우저로 확인하고 실행한 범위만 `docs/verification.md`에 남긴다.
