고객의 상황을 가정해 모바일 시안을 직접 눌러봤습니다. 목표와 다른 안내, 선택 손실, 요청서 불일치를 고쳤습니다. 등록·기록·실제 제안 비교는 아직 검토할 화면이 필요합니다.

실제 사용자 조사 결과가 아닙니다.
가상의 상황을 적용한 브라우저 검토입니다. 만족도·구매 의사·성공률은 측정하지 않았습니다.

현재 흐름에서 고친 것

01 · 목표에 맞는 도움

분갈이·회복을 골라도 가지 정리 상담이 나왔습니다.

목표별 안내·준비 항목을 나눴습니다. 가이드에서 수형을 열면 이전 분갈이 목표가 아닌 수형으로 시작합니다.

02 · 돌아와도 남는 선택

다른 아이템을 보고 돌아오면 목표와 예산이 초기화됐습니다.

같은 화면을 열어둔 동안 각 아이템의 목표·조건·도움 방식을 유지합니다.

03 · 최신 조건을 보여주는 요청서

예산을 바꿔도 열린 요청서는 이전 값을 보여줬습니다.

조건·목표·도움 방식이 바뀌면 요청서도 갱신됩니다.

04 · 받는 도움을 이름으로 구분

테라리움은 직접 만들기·공방에서 배우기·완성품 의뢰로 나눴습니다. 직접 할 때에는 ‘준비 내용’을 확인합니다.

05 · 이동한 화면의 시작 찾기

메뉴 전환 시 시작 위치와 제목으로 초점을 옮기고, 요청서를 열면 제목에 초점을 둡니다.

06 · 선택한 식물 이어받기

정원의 스킨답서스에서 조합을 찾으면 해당 식물과 재배치 목표가 함께 이어집니다.

07 · 모를 때 할 수 있는 관찰

‘잘 모르겠어요’에 흙의 촉감·작은 화분 무게 등을 살펴보는 안내를 넣었습니다. 일반 흙 화분에 한정하며 급수를 결정하는 지시는 아닙니다.

08 · 시안에서 되는 일 구분

저장·전송되지 않는 체험임을 표시했습니다. 기존 용기 관리를 약속하던 버튼은 새 작품 제작 버튼으로 바로잡았습니다.

사람의 상황에서 보기

8가지 가상 과업

항목을 누르면 막힌 지점과 남은 범위를 볼 수 있습니다. 이름과 상황은 모두 가상입니다.

P01민지 · 처음 받은 식물

목표 이름과 물 준 날을 몰라도 등록하고 첫 관찰을 시작하기.

확인 등록 진입점이 없습니다. 모름 선택의 관찰 안내는 수정했습니다.

남은 범위 이름 미상 등록 → 첫 기록 → 다음 방문.

P02준호 · 가족과 여러 화분

목표 누가 언제 관리했는지 확인하고 실수한 기록 취소하기.

확인 예시 반응만 있고 담당자·시각·기록·취소는 없습니다.

남은 범위 공동관리 과업은 아직 평가할 수 없습니다.

P03수연 · 분갈이 전 도움 찾기

목표 분갈이 여부를 상담하기 위해 조건 정리하기.

확인 분갈이를 선택해도 수형 상담이 나오던 문제를 수정했습니다.

남은 범위 요청 준비까지만 체험할 수 있습니다. 실제 전문가·가격·작업 제안이 필요합니다.

P04현우 · 가지고 있는 화분 활용

목표 예산과 가진 화분에 맞는 조합을 비교하기.

확인 다른 아이템을 다녀와도 선택이 남고 요청서도 최신 조건으로 바뀝니다.

남은 범위 화분 내부 치수 입력, 실제 후보와 배송 포함 총액이 필요합니다.

P05은서 · 첫 테라리움 수업

목표 직접 만들기·수업·완성품 중 맞는 방식 고르기.

확인 버튼과 요청서에서 ‘공방에서 배우기’의 의미가 일치하도록 수정했습니다.

남은 범위 지역·일정·가격·포함 재료가 없어 실제 수업 선택은 평가할 수 없습니다.

P06지호 · 이미 만든 용기 관리

목표 보유 테라리움의 결로와 환기를 확인하기.

확인 관리 버튼이 신규 제작으로 가던 기대 불일치를 바로잡았습니다.

남은 범위 용기별 관리 화면은 아직 없습니다. 제작과 별도의 과업입니다.

P07다은 · 갑자기 달라진 잎

목표 상태 변화에 필요한 관찰과 상담 자료 확인하기.

확인 가지치기 안내 대신 증상·시점·관리 변화의 확인으로 바꿨습니다.

남은 범위 사진과 이력 연결, 실제 상담이 필요합니다. 진단과 회복 효과를 시험한 것은 아닙니다.

P08영숙 · 작은 화면에서 차근차근

목표 이동한 화면과 대상, 전달할 내용을 놓치지 않기.

확인 메뉴 시작 위치·요청서 초점·선택한 식물 연결을 수정했습니다.

남은 범위 실제 공유 선택은 미지원입니다. 화면 크기 확인이 실제 고령자·스크린리더 검증을 대신하지 않습니다.

다음 검증을 위한 순서

기능 수보다,
끝낼 수 있는 과업.

  1. 등록 → 관찰 → 기록 수정이름 미상·모름을 허용하고 첫 관리 경험을 완결합니다.
  2. 요청서 → 두 제안 비교받는 결과, 가격, 시점, 포함·제외 사항을 보고 고를 수 있게 합니다.
  3. 보유 화분 규격 → 실제 후보실측 정보와 모르는 정보를 구분하고 조합을 비교합니다.
  4. 제작과 별도의 용기 관리결로·환기·수위·장비를 일반 화분과 구분합니다.
  5. 가족 기록과 선택적 공유누가 무엇을 했고 어떤 정보를 전달하는지 확인합니다.

다음에는 실제 사람 5~8명에게 준비된 과업만 제시하는 소규모 관찰을 제안합니다. 미구현 화면은 참가자의 실패로 세지 않습니다.

확인한 것과 남은 것

모바일 화면 크기로 설정한 브라우저에서 목표별 도움 방식, 선택 유지, 요약 갱신, 메뉴 이동과 관찰 안내를 확인했습니다. 실제 휴대폰·스크린리더·고객 인터뷰·결제 실험은 아직 진행하지 않았습니다.
