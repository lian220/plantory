# Plantory 사업기획 검토안

작성일: 2026-09-29 · 갱신: 2026-09-30 · 상태: 사업 가설과 검증 계획 · 문서 열람: PC 기준 · 서비스 형태: 모바일 전용

> 우리집에 맞는 식물을 고르고, 원하는 모습으로 오래 가꾸는 서비스.

## 전체 서비스의 흐름

**조건·총액 비교 → 가상 수령·입양 체크 → 같은 식물 등록·관찰 → 도움 요청 준비 → 개인 경과 계획·재문의**를 이번 개선 시안의 중심으로 묶는다. 내 정원에서는 판매·분양 카드로, 사례에서는 관찰·도움으로, 도움에서는 분갈이·테라리움 준비물 예산으로 이어진다.

하단 메뉴는 **오늘 / 내 정원 / 구매 비교 / 도움 / 사례**다. 상품·사례는 가상이며 입력은 현재 창에서만 유지된다. 실제 전송·상담·결제·실시간 시세·영구 저장은 제공하지 않는다. 이번 우선 작업은 전체 기획과 모바일 시안의 연결 완성도다. 외부 검토 계획은 유지하고 실제 진행 결과와 구분한다.

세부 흐름과 서비스별 대상·입력·결과·예외·운영 책임은 [서비스 안내서](service-guide.md)에 둔다.

## 1. 문서의 역할과 결정 상태

이 문서는 사업 방향, 고객 문제, 수익 구조, 검증 순서를 정리한다. 제품 기능을 구현했다는 의미는 아니다.
함께 제공하는 브라우저 시각화는 사업기획을 검토하는 자료이며, 실제 서비스의 작동이나 출시를 뜻하지 않는다.
사업기획서·서비스 안내서·사용성 보고서는 PC에서 읽기 편한 내부 문서로 구성한다. 모바일 전용 원칙은 실제 서비스와 서비스 시안에 적용한다.

| 구분 | 현재 상태 |
|---|---|
| 승인 범위 | 사업기획·추가 서비스 설계·PC 문서와 연결된 모바일 시안 개선. 커밋·push는 별도 승인 범위에 따름 |
| 확정 방향 | 내부 기획·안내·검토 문서는 PC 열람 기준으로 구성 |
| 확정 방향 | 실제 서비스와 서비스 시안은 모바일 전용. 별도의 데스크톱 서비스 제품은 만들지 않음 |
| 방향 | 관리 기록을 기반으로 식물 선택, 수형·분갈이, 공간·화분, 용기 관리 연결 |
| 확정 방향 | 전체 기획·시안 완성도를 우선 높이고, 준비 후 지인 초보자 무비용 검토. 실제 운영은 전문가·업체 연결부터 검증 |
| 확정 방향 | 일상 관리, 수형·분갈이, 공간·화분, 테라리움의 네 영역 유지 |
| 확정 요구 | 식물·원예자재 구매비용 비교와 신품·중고 함께 확인 |
| 설계안 | 네 영역에서 공통으로 비교하고 화분·용토·자재·장비의 조건·총액과 구입 후 관리 연결 |
| 운영 전제 | 창업자는 기획·운영, 전문 안내는 전문가 협업. 주당 16시간 이상, 초기 전국 온라인, 확보된 파트너 없음 |
| 가설 | 개인화된 관리 이력이 상담 준비와 구매 판단의 번거로움을 줄임 |
| 가설 | 기존 식물의 구체적인 문제 해결에 유료 수요가 존재함 |
| 미결정 | 브랜드 확정, 사업자 형태, 최초 유료 상품, 출시 시점, 가격, 정산 조건 |
| 미결정 | 전문가 선정 기준·제휴처·세부 상담 분야·방문 제공 범위·지원사업 신청 자격 |
| 미결정 | 가격·매물 데이터 확보 경로·플랫폼 연동·갱신 주기·제휴, 구매 비교의 과금·운영 방식 |

‘가설’은 사용자·전문가·판매자에게 검증해야 할 제안이다. 승인된 사업 결과나 시장 사실로 읽지 않는다.
서비스 구성과 화면별 이용 흐름은 [서비스 안내서](service-guide.md)에 정리한다. 아직 실제 참가자 모집·사용자 테스트·유료 수요 검증을 진행하지 않았다.

## 2. 고객에게 제공하려는 변화

식물 구매 시 얻은 정보가 관리로 이어지고, 관리 기록이 다음 상담과 선택에 다시 쓰이도록 한다.
고객이 기억해야 할 일을 줄이고, 자신의 환경과 식물 상태를 설명하는 수고를 줄이는 것이 출발점이다.

- 처음 키우는 사람: 이름을 몰라도 등록하고, 오늘 무엇을 확인할지 이해한다.
- 여러 화분을 키우는 사람: 공간별로 확인하고 대상별 관찰을 구분한다. 가족의 작업 공유는 계정·동기화 준비 후 검토한다.
- 수형을 가꾸는 사람: 가능한 목표와 방법을 비교하고 작업 이후 변화를 남긴다.
- 공간을 꾸미는 사람: 생육 조건과 취향을 구분해 식물·화분 조합을 고른다.
- 테라리움·팔루다리움 사용자: 용기 전체와 구성 식물·장비의 관리를 나누어 기록한다.

핵심 반복 흐름은 **등록 → 상태 확인 → 관찰 기록 → 필요할 때 도움 → 경과 확인**이다. 구매·입양·사례·인계가 같은 식물의 맥락으로 연결된다.
‘오늘 확인’과 ‘오늘 물주기’를 구분하며, 관찰이 부족하면 모른다는 상태를 유지한다.
초보자·다수 화분·용기 사용자 모두 등록할 수 있도록 하되, 검증된 관리 안내의 종별 범위는 제한한다.

## 3. 관리 기반과 세 가지 유료 고객 문제

관리 기능은 고객 관계와 이력이 축적되는 기반이라는 가설이다. 먼저 이름을 모르는 초보자가 등록·관찰·첫 기록을 이해하는지 시안으로 확인한다.
이후 아래 세 문제를 인터뷰와 구체적인 제안으로 비교하고, 반복적으로 결제가 확인되며 제공 가능한 문제부터 유료화한다. 네 서비스 영역을 동시에 실제 운영·출시하는 계획은 아니다.

| 비교 항목 | 기존 식물 수형·분갈이 | 우리집 공간·화분 | 테라리움 제작·관리 |
|---|---|---|---|
| 고객 | 이미 식물을 키우는 사람 | 새 식물을 들이거나 배치를 바꾸는 사람 | 입문자, 작품 보유자, 공방 수강생 |
| 문제 | 너무 크거나 형태가 흐트러짐, 분갈이 판단이 어려움 | 어디에 무엇을 놓을지, 어떤 화분이 맞는지 결정하기 어려움 | 구성·재료·제작 후 관리가 어려움 |
| 구매 계기 | 공간을 벗어난 성장, 작업 필요, 목표 수형 발견 | 이사, 빈 공간, 선물, 기존 화분 교체 | 취미 시작, 수업, 작품 이상, 선물 |
| 지불자 | 식물 소유자 | 공간 사용자 또는 선물 구매자 | 제작자·수강생, 이후 공방 가능 |
| 첫 제안 | 기록을 정리해 전문가에게 상담 연결 | 조건 정리 후 식물·화분 조합 상담 연결 | 목적·용기 조건 정리 후 공방·전문가 연결 |
| 후속 매출 후보 | 직접 상담, 분갈이·지지대 키트 | 직접 배치 상담, 조합 상품 연결 | 재료 키트, 직접 클래스, 수업 후 관리 |
| 주요 원가 | 전문가 시간, 사전 검토, 재문의·분쟁 처리 | 상품 정보 갱신, 상담, 제휴 운영 | 재료·포장·배송, 강사·공간, 사후 문의 |
| 운영 위험 | 부정확한 식별·조언, 예상 수형과 실제 성장 차이 | 규격 불일치, 재고·가격 변화, 이미지와 실물 차이 | 제작 실패, 곰팡이·누수, 파손, 생물 상태 |
| 첫 검증 | 유료 상담 예약과 상담 후 작업 실행 | 조합 제안에 대한 결제 또는 구매 연결 | 수업·키트 결제와 제작 후 관리 지속 |

**후속 유료 문제 비교의 제안:** 기존 식물의 수형·분갈이를 첫 후보로 삼는다.
관리 이력을 바로 활용하고 현재 발생한 문제를 제안으로 만들기 쉽다는 기획 판단이다.
실제 수요나 수익 우위를 확인한 결론은 아니며, 나머지 두 문제도 같은 수준의 제안으로 비교한다.
고객의 긴급도·반복성·지불 의사·제공 원가가 가장 맞는 한 가지를 최초 유료 상품으로 선정한다.

### 네 영역의 공통 핵심: 구매비용 비교

**사용자가 요청한 범위는 식물·원예자재의 구매비용 비교와 신품·중고 함께 확인이다.** 이를 네 영역의 공통 기능으로 기획한다. 일상 관리용 자재, 분갈이 준비물, 공간에 맞는 식물·화분, 테라리움 재료·장비를 비교 대상으로 제안한다. 다나와·네이버의 가격 비교 경험을 참고하면서 생물 상태와 지역 직거래 조건을 다루는 설계안이다.

대표 흐름 설계안은 **검색 → 비교 조건 설정 → 신품·중고 비교 → 구매 총액·상태 확인 → 판매처 이동 → 구입 후 내 식물 등록**이다. 자재·장비는 구입한 식물 또는 관리 작업의 준비물·이력에 연결하는 방향이다. 상세 단계는 종합 요청에 따른 설계 결정이다. 이번 개선 시안에는 가상 상품·매물 비교·가상 수령·입양 연결을 넣고, 실제 판매처 구매와 가격·재고 연동은 후속으로 둔다.

| 구분 | 기획 기준 | 결정 상태 |
|---|---|---|
| 비교 대상 | 식물·원예자재의 신품·중고 구매비용 | 사용자 요구로 포함 |
| 상세 품목·수령 조건 | 화분·용토·원예자재·장비, 배송·지역 직거래 구분 | 설계 제안 |
| 구매 총액 | 선택한 수량·필수 옵션과 배송비를 합산하고 각 항목 표시 | 설계 제안 |
| 비교의 신뢰 범위 | 출처·확인 시각·미확인 항목 표시, 판매 유형·물품 상태 구분 | 설계 제안 |
| 식물의 비교 조건 | 품종·크기·발근/삽수·상태·화분 포함 여부 | 설계 제안 |
| 자재·장비의 비교 조건 | 같은 모델·규격, L/kg/개 등 같은 단위의 가격 | 설계 제안 |
| 결과 구분 | 동일 상품과 조건이 비슷한 대안을 구분해 다른 이유 설명 | 설계 제안 |
| 전체 준비물 구매 합계 | 보유품 제외, 필수·선택 품목, 판매처별 배송비 구분 | 이번 개선 시안의 가상 예산·보유품 제외·판매처별 배송 |

식물의 신규 판매와 개인 분양은 모두 중고로 분류하지 않는다. 판매 유형과 발근·손상 등 생물 상태를 따로 표시하고, 중고 화분·장비의 사용 상태도 구분한다. 용토의 L와 kg을 근거 없이 환산하거나 규격·구성이 다른 물품을 같은 상품의 최저가로 묶지 않는다.

공개 매물 가격은 판매자의 **호가**다. 거래 완료 표시만으로 실제 거래 금액을 안다고 가정하지 않는다. 배송비·필수 옵션 비용을 모르면 0원으로 채우지 않고 ‘확인된 금액 + 미확인 비용’으로 보여준다. 총액을 알 수 없는 후보를 확정 최저가로 순위 매기지 않는다. 지역 직거래는 장소와 수령 조건을 배송 상품과 구분한다.

네이버·당근·번개장터·중고나라 등은 출처 후보다. 자동 통합, API 이용, 수집, 제휴는 확정하지 않았고 허용된 데이터·표시·갱신 조건을 먼저 확인한다. 공식 출처의 확인 범위·날짜와 추가 서비스 5개 제안은 [조사·검증 문서 7절](research-and-validation.md)에 정리한다.

사업 가설은 비교의 수고와 조건 누락을 줄여 실제 구매 판단을 돕는다는 것이다. 클릭 수를 매출로 대신하지 않으며, 유료 비교·상품 연결 수익이나 수수료는 검증 전이다. 전체 준비물 예산, 보유 물품·규격 확인, 중고 구매 확인표, 가격 알림, 구매내역과 관리 연결은 사용자 동의로 기획 후보에 포함했다. 이번 개선 시안은 가상 총예산·보유품·소포장 비교·입양 확인부터 연결한다. 실제 가격 알림과 구매 내역 연동은 데이터·운영 준비 뒤 검토한다. 검수 및 거래 중개·공동구매도 확정하지 않았다.

**커뮤니티 조사와 후속 선택(2026-09-30):** 실제 비교 사례와 공급자 참여, 구매·상담 이후 결과 확인이 부족하다는 분석을 바탕으로 추가 서비스를 검토했다. 사용자는 **새 식물 입양 체크, 상담·분갈이 후 경과 관리, 내 환경과 비슷한 관리 사례 찾기, 판매·분양 정보 카드**를 기획에 포함하기로 정했다. 이후 종합 요청에 따라 네 흐름을 이번 개선 시안에 연결한다. 실제 운영 범위·출시·공급 조건은 아직 정하지 않았다. 국내 3개·해외 5개 글의 본문을 확인한 소수 사례 분석과 사용자 선택은 수요나 사업성을 검증한 결과가 아니다. 여섯 관점의 분석·남은 후보·검증안은 [조사·검증 문서 8절](research-and-validation.md#community-review)에 정리했다.

추가 서비스는 기존 흐름에 연결한다. 입양 체크는 구입·선물·분양으로 받은 식물의 설명·수령 상태·질문·첫 관찰을 잇는다. 경과 관리는 상담·분갈이 후 확인 항목과 재확인 시점·변화를 재문의 자료로 연결한다. 사례 탐색은 식물·빛·재배 방식·증상별 시도와 결과를 함께 본다. 판매·분양 카드는 개체 사진·크기·상태·구성·수령 조건·관리 이력을 정리한다. 전문가의 지속 관찰·무료 재상담, 사례 공개·자료 확보, 거래 중개·보증은 이 포함 결정만으로 확정하지 않는다.

종합 요청에 따른 추가 설계 판단으로 **소포장 비교·보유품 활용은 이번 개선 시안**, **개인 간 자재 소량 구매·나눔과 상태 공개형 식물 아웃렛도 예시 탐색·조건 정리에 포함**한다. 소포장과 개인 잔량 구매·나눔을 함께 다루는 B안은 사용자가 직접 선택했다. 아웃렛은 전체 완성도를 맡긴 요청에 따른 설계 채택이다. 나눔은 잔량·개봉·보관·지역·수령 기준, 아웃렛은 실제 개체 상태·관리 부담·지원·환불 조건을 확보한 뒤 검증한다. 자체 게시판보다 가상 사례 탐색과 동의받은 실제 사례 확보를 먼저 다룬다.

## 5. 초기 연결에서 직접 제공으로 이어지는 순서

### 단계 0 — 연결된 기획·시안 완성 후 외부 검토

이번에는 구매·준비물·입양·관찰·도움·경과·사례·판매분양이 끊기지 않도록 가상 흐름을 완성한다. 실제 판매처·전문가·가격·사례 성과가 있는 것처럼 표시하지 않는다. 현재 창의 입력은 새로고침하면 초기화된다.

첫 외부 과업은 기존대로 이름 모를 선물 식물의 `등록 → 모름 안내 → 첫 관찰 → 기록 확인`이다. 초보 지인 2~3명 후보가 각자 사용한 뒤 메신저의 같은 질문 다섯 개로 후기를 받는다. 공유 자료가 준비되면 2026-09-30 기준 이번 주에 부탁할 계획이며 참여 수락·실행·배포 결과는 없다. 자기보고로 확인한 이해와 직접 관찰한 행동을 구분한다.

### 단계 A — 관리 기반과 전문가 연결 검증

사용자가 식물·공간·최근 변화를 정리하면 적합한 전문가나 공방을 찾고 상담을 신청하도록 돕는다.
초기 운영은 전국 온라인으로 정하되 상담 분야·가능 시간을 좁혀 수요와 공급을 직접 확인한다. 현재 확보된 파트너는 없으며 방문·운반·공방 수업의 실제 제공 여부는 별도다.
창업자는 주당 16시간 이상 기획·운영에 투입하는 계획이다. 전문 안내 검토와 상담은 해당 분야 전문가와 협업하고, 공급과 운영 부담을 확인해 수용 가능한 인원을 정한다.
연결 수수료, 상담 판매 수수료, 전문가 입점료 중 무엇을 받을지는 제휴 조건과 결제 실험 후 정한다.
상담 가능 인원·응답 시간·가격·제공 범위·취소 조건을 실제 제공 가능한 수준으로 제시한다.
고객 동의 없이 사진과 집 정보·개인 메모를 전문가에게 보내지 않는다.
연결 건수뿐 아니라 완료율·재문의·환불·제공 시간을 함께 본다.

### 실제 공급자와 운영하는 기본 순서

| 단계 | 누구의 역할인가 | 사용자에게 남기는 결과·사업 확인 |
|---|---|---|
| 요청 | 이용자가 대상·문제·공유 범위를 정하고 운영자가 유효 요청 확인 | 요구와 미확인 정보; 제외·추가 질문·공급자 미확보를 구분 |
| 공급자 검토 | 전문가·공방이 분야·자료·이행 가능성 확인 | 제안 가능 여부와 준비에 드는 시간 |
| 조건 제안 | 공급자가 범위·가격·추가 비용·답변 시간·재문의·취소 조건 제시 | 비교 가능한 제안; 내부 가상 예시는 실제 제안으로 세지 않음 |
| 수락 | 고객이 조건을 선택하고 운영자가 진행 조율 | 수락·거절·대기·변경 사유. 클릭과 결제는 구분 |
| 진행 | 전문가가 합의한 상담·작업 제공, 고객이 실제 실행 여부 확인 | 제공 내역·완료 여부·운영 시간·지원 부담 |
| 경과·재문의 | 고객이 변화를 남기고 공급자가 약정 범위 내 대응 | 후속 결과·추가 문의·비용. 무료 재상담·지속 모니터링은 기본 약속 아님 |

공급자 부재, 분야 밖 질문, 가격·응답 조건 미합의는 실제 이용 가능한 제안으로 표시하지 않는다. 시안의 개인 경과 계획은 이 운영 과정에서 발생한 전문가 안내가 아니다.

### 단계 B — 검증된 분야의 직접 상담

초기 연결에서 반복되는 문제와 상담 자료를 정리해 직접 제공 가능한 분야를 선정한다.
조경 관련 자격·재배 경험은 증빙과 실제 상담 가능 범위를 확인해 역할에 반영한다.
자격이 있다고 모든 실내식물·수형·병해충·수조 영역을 다룰 수 있다고 가정하지 않는다.
불확실하거나 전문 영역을 벗어나면 추가 확인 또는 적합한 전문가를 안내한다.
전국 온라인에서 비동기 사진 상담과 실시간 상담 중 무엇을 먼저 제공할지, 가격은 미결정이다. 현장 방문은 후속 공급 검토 대상이다.
상담 이후 관찰 시점과 재문의 범위를 상품 설명에 포함하고, 무제한 상담을 기본 약속으로 두지 않는다.

### 단계 C — 반복 수요에 맞는 키트·클래스

상담에서 자주 필요한 분갈이·유인·테라리움 준비물을 묶어 소량의 키트로 검증한다.
키트별 적용 대상·구성·필요한 추가 준비물·관리법을 제공하고 조합의 적합성을 확인한다.
클래스는 제작 결과뿐 아니라 수업 이후 관리 기록과 문의 흐름까지 묶어 검증한다.
직접 생산·재고 보유·위탁 판매·제휴 연결 방식은 수요, 반품, 보관, 배송 원가 비교 후 선택한다.
식물·재료·전기장비 등의 판매·표시·안전 요건은 상품 확정 시 별도로 검토한다.

| 확장 | 취향 보드, 핀터레스트 분위기·목표 사진 참고 | 링크 저장·허용된 임베드부터; 재사용 권한 확인 |
| 확장 | 테라리움 레시피, 공방 QR, 수업 후 관리 | 식물·배지·조명·장비와 용기 전체 관리 연결 |

| 이번 개선 시안 | 가상 상품·매물의 신품·중고 조건·총액 비교 | 동일 규격과 식물 대안, 미확인 배송비, 상태·출처 예시; 실시간 시세 없음 |
| 이번 개선 시안·운영 후속 | 준비물 총예산·보유품 제외·소포장 비교·입양 확인 | 가상 조건으로 체험; 가격 알림·실제 구매 이력은 데이터 준비 후 |

팔루다리움은 식물·용기·수위·장비 관찰을 다루고, 동물 사육·질병 안내는 초기 범위에서 제외한다.
외부 이미지·상품·중고 매물을 무단 수집할 수 있다고 가정하지 않는다. 허용된 이용 경로를 먼저 확인한다.

## 7. 전문성과 가이드 검증

사용자 입력, 관찰 사실, 센서 측정, 일반 가이드, 전문가 의견, 추정을 구분해서 표시한다.
식물 인식 후보는 사용자가 확정·수정할 수 있게 하고, 불확실하면 종별 작업 안내를 제한한다.
물주기·전정·분갈이를 단일 사진이나 날짜만으로 강제하지 않고 필요한 확인 항목을 제시한다.

- 가이드마다 적용 식물·조건, 참고 출처, 검토자, 검토일, 개정 이력을 관리한다.
- 수형 가이드는 생장 특성, 최근 작업·손상 상태, 가능한 방법과 적용 제외 상황을 검토한다.
- 절단 위치 표시는 초기 기본 기능으로 약속하지 않는다. 불명확하면 추가 사진이나 대면 확인을 요청한다.
- 상담자의 전문 분야·제공 범위를 공개하고, 자격·경력 표현은 확인 가능한 사실로 제한한다.
- AI가 작성한 안내를 전문가 검토 완료 콘텐츠처럼 표시하지 않는다.
- 오류 신고, 가이드 수정, 영향을 받은 이용자 안내 절차를 준비한다.
- 조언과 결과가 다를 때 식물 상태·사용자 실행·안내 내용을 확인할 기록을 남긴다.

정확도·생존율·수형 개선 효과는 측정 전 수치로 홍보하지 않는다. 만족도와 식물의 실제 변화도 따로 본다.

## 8. 실제 서비스의 모바일 전용 고객 경험

휴대전화의 촬영·앨범·한 손 조작·짧은 기록 흐름을 중심으로 설계한다.
초기 형태는 모바일 웹을 기본안으로 하며, 설치형 앱 여부는 촬영·알림·반복 사용 검증 후 결정한다.
데스크톱 전용 화면, 좌우 다중 작업 화면, PC용 편집 기능은 실제 서비스 제품 범위에서 제외한다. 내부 문서에서는 표와 흐름을 비교하기 쉽도록 PC 화면 폭을 활용한다.

| 하단 메뉴 | 고객이 끝내야 할 일·세부 연결 |
|---|---|
| 오늘 | 선택한 식물의 관찰·기록 확인·정정 → 도움·경과 |
| 내 정원 | 등록한 대상 찾기 → 같은 식물 관찰·입양·판매분양 카드 |
| 구매 비교 | 가상 후보·규격·상태·총액 비교 → 가상 수령·입양 체크 |
| 도움 | 기존 가이드와 수형·분갈이·공간·테라리움 조건 정리 → 요청·준비물 예산·개인 경과 계획 |
| 사례 | 환경·재배 방식·증상별 가상 사례 → 관찰·도움 |

첫 시안의 등록 입력은 관리 대상 종류, 이름 또는 이름 모름, 장소를 기준으로 한다. 사진은 요구하지 않으며 모르는 정보는 나중에 보충한다.
가족·전문가와 공유할 때 기록을 선택하며, 집 사진·개인 메모·센서 위치는 기본 공유하지 않는다.
비회원 체험과 기기 간 동기화 방식은 개인정보·저장 지속성 검토 후 결정한다.
로뚜의 다음 행동 안내·선택적 공유·회고는 참고 방향이며, 코드 재사용 여부는 별도 기술 검토 사항이다.

## 9. 수익과 원가 판단 기준

초기에는 방법·상품·전문가 매칭을 검증하며 상담·작업·구매·클래스별 실제 이용 완료에서 수익이 생기는지 확인한다. 계약 전 수수료율이나 수익을 확정하지 않는다.
직접 상담·키트·클래스는 각각 원가표와 운영 능력 검토를 통과한 뒤 추가한다.

| 모델 | 건당 매출 계산 | 반드시 포함할 원가 |
|---|---|---|
| 연결·중개 | 약정 수수료 또는 연결료 | 결제, 고객지원, 전문가 운영, 환불·분쟁 |
| 직접 상담 | 실제 결제액에서 취소·환불 차감 | 사전 검토, 상담, 기록 정리, 사후 문의, 결제 |
| 키트 | 실제 판매액에서 할인·환불 차감 | 재료, 폐기·파손, 포장, 배송, 반품, 안내·지원 |
| 클래스 | 실제 참석·결제 기준 매출 | 강사, 장소, 재료, 준비·정리, 노쇼·환불, 사후 문의 |
| 구독·사업자 도구 | 실제 유료 고객 수와 유지 기간 | 데이터·API, 저장·알림, 연동 유지, 고객지원 |

대표자의 노동도 무료로 계산하지 않는다. 무료 상담과 유료 상담을 분리해 지불 의사를 판단한다.
공헌이익은 순매출에서 거래별 변동비를 빼고 보며, 고객 획득비와 고정비를 포함한 전체 손익은 별도로 계산한다.
기록 수나 추천 클릭을 매출로 대체하지 않는다. 결제·완료·환불·재구매가 이어지는지 확인한다.

## 10. 검증 계획과 진행 조건

### 첫 모바일 시안 검토 — 시안·안내문 준비 후

지인 중 초보자 2~3명을 후보로 둔다. 이름 미상 등록, 모름 선택과 관찰 안내, 첫 기록, 같은 식물의 기록 확인을 혼자 진행한 뒤 메신저로 같은 질문 5개에 답변받는다. 모집 비용은 0원이다. 공유할 시안과 안내문이 준비되면 이번 주(2026-09-30 대화 기준)에 부탁할 계획이며 실제 참여 수락·실행 날짜·접속 방법은 아직 정하지 않았다.
등록 진입을 찾았는지, 관찰과 물주기를 어떻게 이해했는지, 기록 확인·실수 정정에서 어디가 어려웠는지 후기로 확인한다. 자기보고이므로 실제 조작을 직접 관찰한 결과와 구분한다.
도움을 받았다고 한 단계, 기억하는 막힘, 이해한 표현을 남기고 미구현 기능을 참가자 실패로 세지 않는다.
가상 페르소나 검토와 실제 사람의 과업 결과를 구분하며 현재 실제 테스트 결과는 없다. 상세 진행 기준은 [서비스 안내서](service-guide.md#8-첫-사용자-검토의-진행-기준)에 있다.

### 장기 관리 사용성 실험 — 후속 제안

첫 시안 검토와 기록 지속성·제공 범위가 준비된 뒤 검토할 제안 규모는 사용자 20명·4주다. 확정 모집 계획이 아니다. 초보, 여러 화분, 용기 유형을 포함하고 결과는 유형별로도 본다.
등록 성공은 도움 없이 식물 또는 용기를 등록하고 첫 관찰 기록까지 남긴 경우로 정의한다.
4주 차 사용은 화면 방문·알림 클릭이 아니라 실제 관찰·관리 기록 작성으로 정의한다.
초기 목표는 16명 이상 등록 성공, 10명 이상 4주 차 기록이다. 제안 목표이며 업계 기준이 아니다.
표본이 작으므로 합산 수치만으로 시장성이나 생존율 개선을 주장하지 않는다.

### 구매비용 비교 사용성 — 추가 검토 후보

첫 초보자 관찰 과업을 유지하고, 비교 화면이 준비된 뒤 별도 과업으로 검토한다. 예를 들어 ‘필요한 규격의 화분과 용토를 고르고, 배송비와 필수 옵션까지 포함해 구입 후보를 정하라’는 상황을 제시할 수 있다.
동일 상품과 유사 대안을 구분하는지, 중고·개인 분양의 상태를 확인하는지, 미확인 배송비를 알아보고 직거래와 배송을 다르게 판단하는지를 관찰한다.
이번 개선 시안의 가상 준비물 합계와 보유품 제외·소포장 비교를 추가 과업으로 살펴본다. 화면 선택·가상 수령·실제 구매를 구분하며, 가상 데이터 체험을 실제 거래나 시세 검증으로 세지 않는다. 실제 참가자 결과는 아직 없다.

### 세 유료 문제 비교

같은 수준의 설명과 구체적인 가격·범위를 제시해 상담 예약·실제 결제·취소 이유를 비교한다.
수형·분갈이, 공간·화분, 테라리움 각각 고객 상황·최근 지출·현재 해결 방법·제공 시간을 기록한다.
전문가·공방의 응대 범위·시간·정산·책임 경계를 확인한 뒤 실제 상담 실험에 참여시킨다.
출시한 것처럼 위장하거나 제공할 수 없는 유료 예약을 받지 않는다.
우선순위는 실제 결제, 문제 반복성, 제공 가능한 공급, 건당 원가와 문의 부담을 함께 평가해 정한다.

### 다음 단계 진행 조건

- 직접 상담: 반복 문제와 상담 기준이 정리되고, 검토된 범위에서 품질·응답 시간을 유지할 수 있음.
- 키트: 구성·구매 수요가 확인되고, 소량 판매의 반품·배송·지원 원가를 설명할 수 있음.
- 클래스: 강사·공간·재료가 확보되고, 준비부터 사후 문의까지 운영 가능함.
- 센서: 데이터 접근과 지원 기기가 확인되고, 오래된 측정값을 관리 판단에서 구분할 수 있음.
- 자동 급수·정밀 전정: 별도 검증에서 오류와 실패 대응을 다룬 후 제품 포함 여부 결정.

## 11. 정부지원 사업과 연결할 근거

사업 설명은 ‘가정별 재배환경과 식물 관리·성장 이력을 연결해 선택부터 수형 관리까지 돕는 서비스’로 정리한다.
정부지원금 확보 자체를 고객 수요나 지속 가능한 수익의 증거로 보지 않는다.
개발 역량·조경 관련 자격·재배 경험은 자료로 증명하고, 외부 전문가가 필요한 영역을 제시한다.
사업자등록 여부·개업일·대표자 나이·창업 지역·중복 지원 이력을 확인하기 전 지원사업을 확정하지 않는다.
현재 문서에는 접수 중 사업, 지급 금액, 선정 가능성에 대한 확인된 판단을 포함하지 않는다.
공고 원문·첨부파일의 자격, 제외 조건, 자부담, 평가 항목, 사업비 사용 범위를 확인한 뒤 신청안을 작성한다.
검증 자료는 인터뷰, 이용 기록, 상담·구매 결과, 비용, 가이드 검토 이력, 파트너 협의로 구성한다.
폐기 감소·탄소 저감·생존율 개선·지역 일자리 효과는 측정 방법과 데이터가 있을 때에만 성과로 제시한다.

## 12. 다음 의사결정

현재 우선 작업은 추가 질문 없이 전체 서비스 설계와 연결된 모바일 시안의 완성도를 높이는 것이다. 대표 흐름·가상 데이터·예외 상태를 문서와 함께 정리하고 브라우저에서 확인한다. 첫 외부 검토는 초보 지인 2~3명 후보에게 혼자 사용한 뒤 메신저 후기를 받는 기존 계획을 유지한다.

실제 운영 전에는 최초 유료 문제, 공급자, 책임 범위, 제공 가능한 조건과 검증 비용을 정한다. 순서는 **전체 기획·개선 시안 → 외부 사용성 검토·데이터/공급 준비 → 유료 문제 비교 → 검증된 직접 상담 → 키트·클래스**다. 공간·화분과 테라리움의 실제 요청·이행 근거가 더 좋으면 최초 유료 문제의 순서를 바꾼다. 연결된 시안을 만든다는 결정은 전체 아이디어를 동시에 출시한다는 뜻이 아니다.
