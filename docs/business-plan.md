# Plantory 사업기획 검토안

작성일: 2026-09-29 · 상태: 사업 가설과 검증 계획 · 제공 형태: 모바일 전용

> 우리집에 맞는 식물을 고르고, 원하는 모습으로 오래 가꾸는 서비스.

## 1. 문서의 역할과 결정 상태

이 문서는 사업 방향, 고객 문제, 수익 구조, 검증 순서를 정리한다. 제품 기능을 구현했다는 의미는 아니다.
함께 제공하는 브라우저 시각화는 사업기획을 검토하는 자료이며, 실제 서비스의 작동이나 출시를 뜻하지 않는다.

| 구분 | 현재 상태 |
|---|---|
| 승인 | 사업기획 문서화, 브라우저 시각화, 저장소 반영·push |
| 승인 | 모바일 전용 서비스 방향. 별도의 데스크톱 제품은 만들지 않음 |
| 방향 | 관리 기록을 기반으로 식물 선택, 수형·분갈이, 공간·화분, 용기 관리 연결 |
| 방향 | 초기에는 전문가·업체 연결을 검증하고, 이후 직접 상담·키트·클래스 검토 |
| 가설 | 개인화된 관리 이력이 상담 준비와 구매 판단의 번거로움을 줄임 |
| 가설 | 기존 식물의 구체적인 문제 해결에 유료 수요가 존재함 |
| 미결정 | 브랜드 확정, 사업자 형태, 최초 유료 상품, 출시 시점, 가격, 정산 조건 |
| 미결정 | 전문가 선정 기준, 제휴처, 지역, 지원사업 신청 자격 |

‘가설’은 사용자·전문가·판매자에게 검증해야 할 제안이다. 승인된 사업 결과나 시장 사실로 읽지 않는다.

## 2. 고객에게 제공하려는 변화

식물 구매 시 얻은 정보가 관리로 이어지고, 관리 기록이 다음 상담과 선택에 다시 쓰이도록 한다.
고객이 기억해야 할 일을 줄이고, 자신의 환경과 식물 상태를 설명하는 수고를 줄이는 것이 출발점이다.

- 처음 키우는 사람: 이름을 몰라도 등록하고, 오늘 무엇을 확인할지 이해한다.
- 여러 화분을 키우는 사람: 공간별로 확인하고 가족의 작업과 중복되지 않게 기록한다.
- 수형을 가꾸는 사람: 가능한 목표와 방법을 비교하고 작업 이후 변화를 남긴다.
- 공간을 꾸미는 사람: 생육 조건과 취향을 구분해 식물·화분 조합을 고른다.
- 테라리움·팔루다리움 사용자: 용기 전체와 구성 식물·장비의 관리를 나누어 기록한다.

핵심 반복 흐름은 **등록 → 상태 확인 → 행동 선택 → 기록 → 다음 확인**이다.
‘오늘 확인’과 ‘오늘 물주기’를 구분하며, 관찰이 부족하면 모른다는 상태를 유지한다.
초보자·다수 화분·용기 사용자 모두 등록할 수 있도록 하되, 검증된 관리 안내의 종별 범위는 제한한다.

## 3. 관리 기반과 세 가지 유료 고객 문제

관리 기능은 고객 관계와 이력이 축적되는 기반이다. 아래 세 문제를 같은 우선순위로 개발하지 않는다.
인터뷰와 구체적인 제안으로 비교하고, 반복적으로 결제가 확인되며 제공 가능한 문제부터 유료화한다.

| 비교 항목 | 기존 식물 수형·분갈이 | 우리집 공간·화분 | 테라리움 제작·관리 |
|---|---|---|---|
| 고객 | 이미 식물을 키우는 사람 | 새 식물을 들이거나 배치를 바꾸는 사람 | 입문자, 작품 보유자, 공방 수강생 |
| 문제 | 너무 크거나 형태가 흐트러짐, 분갈이 판단이 어려움 | 어디에 무엇을 놓을지, 어떤 화분이 맞는지 결정하기 어려움 | 구성·재료·제작 후 관리가 어려움 |
| 구매 계기 | 공간을 벗어난 성장, 작업 필요, 목표 수형 발견 | 이사, 빈 공간, 선물, 기존 화분 교체 | 취미 시작, 수업, 작품 이상, 선물 |
| 지불자 | 식물 소유자 | 공간 사용자 또는 선물 구매자 | 제작자·수강생, 이후 공방 가능 |
| 첫 제안 | 기록을 정리해 전문가에게 상담 연결 | 조건 정리 후 식물·화분 조합 상담 연결 | 목적·용기 조건 정리 후 공방·전문가 연결 |
| 후속 매출 후보 | 직접 상담, 분갈이·지지대 키트 | 직접 배치 상담, 조합 상품 연결 | 재료 키트, 직접 클래스, 수업 후 관리 |
| 주요 원가 | 전문가 시간, 사전 검토, 재문의·분쟁 처리 | 상품 정보 갱신, 상담, 제휴 운영 | 재료·포장·배송, 강사·공간, 사후 문의 |
| 운영 위험 | 부정확한 식별·조언, 예상 수형과 실제 성장 차이 | 규격 불일치, 재고·가격 변화, 이미지와 실물 차이 | 제작 실패, 곰팡이·누수, 파손, 생물 상태 |
| 첫 검증 | 유료 상담 예약과 상담 후 작업 실행 | 조합 제안에 대한 결제 또는 구매 연결 | 수업·키트 결제와 제작 후 관리 지속 |

**우선 검증 제안:** 기존 식물의 수형·분갈이를 첫 후보로 삼는다.
관리 이력을 바로 활용하고 현재 발생한 문제를 제안으로 만들기 쉽다는 기획 판단이다.
실제 수요나 수익 우위를 확인한 결론은 아니며, 나머지 두 문제도 같은 수준의 제안으로 비교한다.
고객의 긴급도·반복성·지불 의사·제공 원가가 가장 맞는 한 가지를 최초 유료 상품으로 선정한다.

기본 기록의 수정·삭제는 무료로 유지하는 방향이며, 개인 데이터 접근을 과금 압박 수단으로 삼지 않는다.

## 5. 초기 연결에서 직접 제공으로 이어지는 순서

### 단계 A — 관리 기반과 전문가 연결 검증

사용자가 식물·공간·최근 변화를 정리하면 적합한 전문가나 공방을 찾고 상담을 신청하도록 돕는다.
초기 운영 지역·상담 분야·가능 시간을 좁혀 수요와 공급을 직접 확인한다.
연결 수수료, 상담 판매 수수료, 전문가 입점료 중 무엇을 받을지는 제휴 조건과 결제 실험 후 정한다.
상담 가능 인원·응답 시간·가격·제공 범위·취소 조건을 실제 제공 가능한 수준으로 제시한다.
고객 동의 없이 사진과 집 정보·개인 메모를 전문가에게 보내지 않는다.
연결 건수뿐 아니라 완료율·재문의·환불·제공 시간을 함께 본다.

### 단계 B — 검증된 분야의 직접 상담

초기 연결에서 반복되는 문제와 상담 자료를 정리해 직접 제공 가능한 분야를 선정한다.
조경 관련 자격·재배 경험은 증빙과 실제 상담 가능 범위를 확인해 역할에 반영한다.
자격이 있다고 모든 실내식물·수형·병해충·수조 영역을 다룰 수 있다고 가정하지 않는다.
불확실하거나 전문 영역을 벗어나면 추가 확인 또는 적합한 전문가를 안내한다.
사진 상담, 실시간 상담, 현장 방문 중 첫 제공 형태와 가격은 미결정이다.
상담 이후 관찰 시점과 재문의 범위를 상품 설명에 포함하고, 무제한 상담을 기본 약속으로 두지 않는다.

### 단계 C — 반복 수요에 맞는 키트·클래스

상담에서 자주 필요한 분갈이·유인·테라리움 준비물을 묶어 소량의 키트로 검증한다.
키트별 적용 대상·구성·필요한 추가 준비물·관리법을 제공하고 조합의 적합성을 확인한다.
클래스는 제작 결과뿐 아니라 수업 이후 관리 기록과 문의 흐름까지 묶어 검증한다.
직접 생산·재고 보유·위탁 판매·제휴 연결 방식은 수요, 반품, 보관, 배송 원가 비교 후 선택한다.
식물·재료·전기장비 등의 판매·표시·안전 요건은 상품 확정 시 별도로 검토한다.

| 확장 | 취향 보드, 핀터레스트 분위기·목표 사진 참고 | 링크 저장·허용된 임베드부터; 재사용 권한 확인 |
| 확장 | 테라리움 레시피, 공방 QR, 수업 후 관리 | 식물·배지·조명·장비와 용기 전체 관리 연결 |
| 사업 확장 | 식물가게 구매 후 관리, 공방 도구, 사무실 관리 업무 | 지불자·운영 문제 별도 검증; 초기 동시 개발 안 함 |
| 연동 후속 | 가격 비교, 중고나라 등 매물 탐색, 매물 질문 도우미 | 출처·규격·상태·배송비·관측 시점 구분 |
| 연동 후속 | 시세 범위·가격 조건 맞추기, 실제 상품 구매 연결 | 호가와 거래가 구분; 수집·이용 권한 확보 |
| 연동 후속 | 센서 온습도·토양수분, 이상·연결 끊김 알림 | 기기별 의미·측정 시각·배지 차이 확인 |
| 연구 | 자동 급수, 정밀 절단 위치, 성장 예측 | 오작동·판단 오류 검증 후 범위 결정 |

팔루다리움은 식물·용기·수위·장비 관찰을 다루고, 동물 사육·질병 안내는 초기 범위에서 제외한다.
외부 이미지·상품·중고 매물을 무단 수집할 수 있다고 가정하지 않는다. 허용된 이용 경로를 먼저 확인한다.

## 7. 전문성과 가이드 검증

사용자 입력, 관찰 사실, 센서 측정, 일반 가이드, 전문가 의견, 추정을 구분해서 표시한다.
식물 인식 후보는 사용자가 확정·수정할 수 있게 하고, 불확실하면 종별 작업 안내를 제한한다.
물주기·전정·분갈이를 단일 사진이나 날짜만으로 강제하지 않고 필요한 확인 항목을 제시한다.

- 가이드마다 적용 식물·조건, 참고 출처, 검토자, 검토일, 개정 이력을 관리한다.
- 수형 가이드는 생장 특성, 최근 작업·손상 상태, 가능한 방법과 적용 제외 상황을 검토한다.
- 절단 위치 표시는 초기 기본 기능으로 약속하지 않는다. 불명확하면 추가 사진이나 대면 확인을 요청한다.
- 상담자의 전문 분야·제공 범위를 공개하고, 자격·경력 표현은 확인 가능한 사실로 제한한다.
- AI가 작성한 안내를 전문가 검토 완료 콘텐츠처럼 표시하지 않는다.
- 오류 신고, 가이드 수정, 영향을 받은 이용자 안내 절차를 준비한다.
- 조언과 결과가 다를 때 식물 상태·사용자 실행·안내 내용을 확인할 기록을 남긴다.

정확도·생존율·수형 개선 효과는 측정 전 수치로 홍보하지 않는다. 만족도와 식물의 실제 변화도 따로 본다.

## 8. 모바일 전용 고객 경험

휴대전화의 촬영·앨범·한 손 조작·짧은 기록 흐름을 중심으로 설계한다.
초기 형태는 모바일 웹을 기본안으로 하며, 설치형 앱 여부는 촬영·알림·반복 사용 검증 후 결정한다.
데스크톱 전용 화면, 좌우 다중 작업 화면, PC용 편집 기능은 제품 범위에서 제외한다.

| 화면 | 고객이 끝내야 할 일 |
|---|---|
| 오늘 | 확인할 식물을 고르고 상태·행동을 빠르게 기록 |
| 내 정원 | 공간별 식물·용기와 기록을 찾고 수정 |
| 찾기·꾸미기 | 식물 검색, 취향·조합 저장, 조건 정리 |
| 가이드 | 수형·분갈이·용기 관리 방법을 확인하고 상담으로 연결 |
| 식물 상세 | 관리·사진·수형·정보를 하나의 개체 이력으로 연결 |

등록 최소 입력은 사진 또는 이름, 관리 대상 종류, 장소를 기준으로 검토한다. 모르는 정보는 나중에 보충한다.
가족·전문가와 공유할 때 기록을 선택하며, 집 사진·개인 메모·센서 위치는 기본 공유하지 않는다.
비회원 체험과 기기 간 동기화 방식은 개인정보·저장 지속성 검토 후 결정한다.
로뚜의 다음 행동 안내·선택적 공유·회고는 참고 방향이며, 코드 재사용 여부는 별도 기술 검토 사항이다.

## 9. 수익과 원가 판단 기준

초기에는 방법·상품·전문가 매칭을 검증하며 상담·작업·구매·클래스별 실제 이용 완료에서 수익이 생기는지 확인한다. 계약 전 수수료율이나 수익을 확정하지 않는다.
직접 상담·키트·클래스는 각각 원가표와 운영 능력 검토를 통과한 뒤 추가한다.

| 모델 | 건당 매출 계산 | 반드시 포함할 원가 |
|---|---|---|
| 연결·중개 | 약정 수수료 또는 연결료 | 결제, 고객지원, 전문가 운영, 환불·분쟁 |
| 직접 상담 | 실제 결제액에서 취소·환불 차감 | 사전 검토, 상담, 기록 정리, 사후 문의, 결제 |
| 키트 | 실제 판매액에서 할인·환불 차감 | 재료, 폐기·파손, 포장, 배송, 반품, 안내·지원 |
| 클래스 | 실제 참석·결제 기준 매출 | 강사, 장소, 재료, 준비·정리, 노쇼·환불, 사후 문의 |
| 구독·사업자 도구 | 실제 유료 고객 수와 유지 기간 | 데이터·API, 저장·알림, 연동 유지, 고객지원 |

대표자의 노동도 무료로 계산하지 않는다. 무료 상담과 유료 상담을 분리해 지불 의사를 판단한다.
공헌이익은 순매출에서 거래별 변동비를 빼고 보며, 고객 획득비와 고정비를 포함한 전체 손익은 별도로 계산한다.
기록 수나 추천 클릭을 매출로 대체하지 않는다. 결제·완료·환불·재구매가 이어지는지 확인한다.

## 10. 검증 계획과 진행 조건

### 관리 사용성 실험

제안 규모는 사용자 20명·4주다. 초보, 여러 화분, 용기 유형을 포함하고 결과는 유형별로도 본다.
등록 성공은 도움 없이 식물 또는 용기를 등록하고 첫 관찰 기록까지 남긴 경우로 정의한다.
4주 차 사용은 화면 방문·알림 클릭이 아니라 실제 관찰·관리 기록 작성으로 정의한다.
초기 목표는 16명 이상 등록 성공, 10명 이상 4주 차 기록이다. 제안 목표이며 업계 기준이 아니다.
표본이 작으므로 합산 수치만으로 시장성이나 생존율 개선을 주장하지 않는다.

### 세 유료 문제 비교

같은 수준의 설명과 구체적인 가격·범위를 제시해 상담 예약·실제 결제·취소 이유를 비교한다.
수형·분갈이, 공간·화분, 테라리움 각각 고객 상황·최근 지출·현재 해결 방법·제공 시간을 기록한다.
전문가·공방의 응대 범위·시간·정산·책임 경계를 확인한 뒤 실제 상담 실험에 참여시킨다.
출시한 것처럼 위장하거나 제공할 수 없는 유료 예약을 받지 않는다.
우선순위는 실제 결제, 문제 반복성, 제공 가능한 공급, 건당 원가와 문의 부담을 함께 평가해 정한다.

### 다음 단계 진행 조건

- 직접 상담: 반복 문제와 상담 기준이 정리되고, 검토된 범위에서 품질·응답 시간을 유지할 수 있음.
- 키트: 구성·구매 수요가 확인되고, 소량 판매의 반품·배송·지원 원가를 설명할 수 있음.
- 클래스: 강사·공간·재료가 확보되고, 준비부터 사후 문의까지 운영 가능함.
- 센서: 데이터 접근과 지원 기기가 확인되고, 오래된 측정값을 관리 판단에서 구분할 수 있음.
- 자동 급수·정밀 전정: 별도 검증에서 오류와 실패 대응을 다룬 후 제품 포함 여부 결정.

## 11. 정부지원 사업과 연결할 근거

사업 설명은 ‘가정별 재배환경과 식물 관리·성장 이력을 연결해 선택부터 수형 관리까지 돕는 서비스’로 정리한다.
정부지원금 확보 자체를 고객 수요나 지속 가능한 수익의 증거로 보지 않는다.
개발 역량·조경 관련 자격·재배 경험은 자료로 증명하고, 외부 전문가가 필요한 영역을 제시한다.
사업자등록 여부·개업일·대표자 나이·창업 지역·중복 지원 이력을 확인하기 전 지원사업을 확정하지 않는다.
현재 문서에는 접수 중 사업, 지급 금액, 선정 가능성에 대한 확인된 판단을 포함하지 않는다.
공고 원문·첨부파일의 자격, 제외 조건, 자부담, 평가 항목, 사업비 사용 범위를 확인한 뒤 신청안을 작성한다.
검증 자료는 인터뷰, 이용 기록, 상담·구매 결과, 비용, 가이드 검토 이력, 파트너 협의로 구성한다.
폐기 감소·탄소 저감·생존율 개선·지역 일자리 효과는 측정 방법과 데이터가 있을 때에만 성과로 제시한다.

## 12. 다음 의사결정

첫 결정은 ‘어떤 고객 문제를 어떤 범위와 가격으로 실제 제공할 것인가’다.
기능 구현 전 관리 흐름, 최초 유료 문제, 공급자, 책임 범위, 첫 검증 비용과 일정을 확정한다.
제안 순서는 **관리 기반 → 기존 식물 수형·분갈이 연결 검증 → 검증된 직접 상담 → 키트·클래스**다.
공간·화분과 테라리움의 실험 결과가 더 좋으면 최초 유료 문제의 순서를 바꾼다. 전체 아이디어를 동시에 출시하지 않는다.
